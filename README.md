# BlankVPN Auto Updater

Утилита для автоматической балансировки серверов BlankVPN на **Keenetic + XKeen/Xray**.

Получает серверы из подписки, настраивает `leastPing`, Observatory и автоматически обновляет конфигурацию.

## Требования
- Keenetic с USB
- Entware
- установленный и работающий XKeen/Xray
- SSH-доступ к роутеру
- активная подписка BlankVPN

Сначала настройте XKeen по [официальной инструкции BlancVPN](https://blancvpn.shop/ru/help/xkeen-setup-guide-for-keenetic-routers).

Утилита устанавливается **поверх готового XKeen**.

## Установка

Загрузите `install-blancvpn.sh` на роутер, например в `/opt`.

Запустите:

```sh
sh /opt/install-blancvpn.sh
```

Выберите:

```text
1) Установить
2) Удалить
```

При установке скрипт запросит:

1. URL подписки BlankVPN
2. период обновления

Доступные интервалы:

```text
1, 2, 3, 4, 6, 8, 12, 24 часа
```

По умолчанию — **6 часов**.

## Что делает скрипт

- создаёт 6 серверов BlankVPN;
- исключает `Extra Whitelist` и `Extra Whitelist2`;
- настраивает `leastPing`;
- создаёт или обновляет Observatory;
- добавляет необходимые правила маршрутизации;
- сохраняет существующие настройки;
- проверяет конфигурацию перед применением;
- создаёт резервные копии;
- автоматически обновляет серверы по расписанию.

Если `07_observatory.json` отсутствует, скрипт создаёт его сам.

## Удаление

Запустите скрипт снова:

```sh
sh /opt/install-blancvpn.sh
```

Выберите:

```text
2) Удалить
```

Скрипт отключит автоматическое обновление, удалит свои настройки и восстановит предыдущую конфигурацию.

## Важно

Если необходимо обновить сервера до истечения интервала, примените команду:

```sh
/opt/sbin/blanc-auto-update
```
