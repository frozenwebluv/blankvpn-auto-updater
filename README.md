# BlankVPN Auto Updater

Утилита для автоматического обновления серверов BlankVPN на **Keenetic + XKeen/Xray**.

Получает серверы из подписки, выбирает обычные Extra, настраивает `leastPing` и обновляет конфигурацию по расписанию. Для установки нужен **один файл**.

**Текущая версия: 0.1.0-rc.3 — тестовый выпуск.**

## Требования

- Keenetic с настроенным Entware;
- установленный и работающий XKeen/Xray;
- SSH-доступ к роутеру от root;
- активная подписка BlankVPN с узлами Extra VLESS TCP/REALITY;
- `jq-full` с поддержкой regex, `coreutils-timeout` и `curl`.

Сначала настройте XKeen по [официальной инструкции BlancVPN](https://blancvpn.shop/ru/help/xkeen-setup-guide-for-keenetic-routers). Утилита устанавливается **поверх готового XKeen**.

Установщик проверяет зависимости, но не устанавливает их сам. Сокращённый пакет `jq` без ONIGURUMA не подходит: нужен `jq-full`. Если Entware сообщает о конфликте этих пакетов, требуется заменить `jq`, а не устанавливать `jq-full` поверх него.

## Установка

**1.** [Скачайте install-blancvpn.sh](https://github.com/frozenwebluv/blankvpn-auto-updater/raw/refs/heads/main/install-blancvpn.sh) и загрузите его на роутер в `/opt`.

**2.** В SSH-терминале выполните:

```sh
sh /opt/install-blancvpn.sh
blancvpn set-url
```

Вставьте ссылку подписки и нажмите Enter. Ввод скрыт. Сама установка ещё не меняет работающий VPN.

**3.** Задайте настройки и проверьте подписку:

```sh
blancvpn configure --nodes 6 --strategy leastPing --fallback block --hours 2
blancvpn preview
```

Продолжайте, если проверка завершилась сообщением `Stage accepted by Xray`.

**4.** Отключите прежний обновлятор, примените настройки и включите расписание:

```sh
blancvpn schedule disable-legacy
blancvpn activate
blancvpn schedule enable
blancvpn status
```

Готово: серверы обновляются **каждые 2 часа**. Если серверы не изменились, Xray не перезапускается.

Установочный файл после успешной установки больше не нужен:

```sh
rm -f /opt/install-blancvpn.sh
```

## Команды управления

| Действие | Команда |
|---|---|
| Посмотреть состояние | `blancvpn status` |
| Узнать версию | `blancvpn version` |
| Обновить серверы сейчас | `blancvpn update` |
| Проверить без применения | `blancvpn preview` |
| Заменить ссылку подписки | `blancvpn set-url` |
| Выключить автообновление | `blancvpn schedule disable` |
| Включить автообновление | `blancvpn schedule enable` |
| Показать все команды | `blancvpn help` |

После замены подписки выполните `blancvpn preview`, затем `blancvpn update`.

## Изменение периода обновления

Например, каждые 6 часов:

```sh
blancvpn configure --hours 6
blancvpn schedule enable
```

Доступные интервалы: **1, 2, 3, 4, 6, 8, 12 или 24 часа**.

## Если VPN-серверы недоступны

В инструкции используется `block`: при отказе всех выбранных серверов управляемый VPN-маршрут блокируется. Существующие прямые исключения продолжают работать.

Чтобы разрешить прямой выход при отказе VPN:

```sh
blancvpn configure --fallback direct
blancvpn preview
blancvpn update
```

Для этого в XKeen должен быть outbound `direct`. В режиме `direct` соединение при отказе VPN может идти **без VPN**.

## Отключение и возврат прежних настроек

```sh
blancvpn schedule disable
blancvpn deactivate
```

Утилита возвращает затронутые конфиги к состоянию до первой активации и перезапускает XKeen. Старое расписание обновлятора автоматически не включается. Если конфиги были изменены другой программой, утилита откажется их перезаписывать.

## Что сохраняется на роутере

- рабочая программа и необходимые библиотеки;
- настройки и приватная ссылка подписки;
- одна исходная копия конфигов для восстановления и одна исходная копия расписания;
- небольшой журнал работы.

**История бэкапов не накапливается.** Временная копия удаляется после успешного обновления; при незавершённом восстановлении остаётся до команды `blancvpn recover`.

## Проверено

Установка, активация и обновление проверены на **Keenetic Hopper SE KN-3812, KeeneticOS 5.1.7, XKeen 2.1 и Xray 26.9.30**. Пройдены **39 автоматических тестов** с проверкой конфигураций настоящим Xray.

Версия остаётся тестовой: длительная работа и другие модели ещё не проверены. Утилита обновляет конфигурацию, но не гарантирует доступность серверов VPN.
